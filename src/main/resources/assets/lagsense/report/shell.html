About these measurements

Target and event timings include the work they call, so the same work can appear in more than one result. CPU samples show which Java code was running when each sample was taken. Their percentages describe how often code appeared in the samples rather than CPU usage or elapsed time.

A missing result does not mean an object used no time or was removed from the world. Some activity cannot be measured, and any known capture limits are shown above.

This file may include coordinates, thread names and UUIDs. Review it before sharing.
